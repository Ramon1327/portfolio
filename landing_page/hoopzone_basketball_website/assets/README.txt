# HoopZone Basketball Landing Page

Files:
- index.html — page structure and Bootstrap 5 components
- css/style.css — custom dark/orange visual design
- js/script.js — navbar behavior, mobile menu, scroll spy, animated stats
- assets/design-reference.png — generated visual reference used for the design

Images:
The photographic backgrounds use free-to-use Unsplash images through `images.unsplash.com` URLs. 
For production/portfolio hosting, you can download the images from their Unsplash pages and replace the remote URLs with local files in `assets/images/`.

Main source references:
- Basketball dunk: https://unsplash.com/photos/a-person-jumping-up-into-the-air-to-dunk-a-basketball-ZQXlJJ6XZFE
- Basketball team: https://unsplash.com/photos/a-group-of-young-men-playing-a-game-of-basketball-tCoj6_GZC3c
- Basketball game: https://unsplash.com/photos/basketball-game-WNJVjkjkh44
- Grayscale basketball players: https://unsplash.com/photos/grayscale-basketball-players-UFIZodJgScQ

The page is designed as a portfolio sample and can be renamed/rebranded easily.
