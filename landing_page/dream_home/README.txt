DREAM HOME REALTY — STATIC WEBSITE

FILES
- index.html: complete responsive Bootstrap 5.3 website
- assets/house-hero.png: generated real-estate hero image

TECH
- HTML5
- Custom CSS
- Vanilla JavaScript
- Bootstrap 5.3.8 via jsDelivr CDN
- Google Fonts: Montserrat + Great Vibes

RUN
1. Extract the ZIP.
2. Keep the assets folder beside index.html.
3. Double-click index.html, or serve the folder with any local web server.

CUSTOMIZE
- Change colors in :root near the top of index.html.
- Replace assets/house-hero.png with your own property image.
- Replace sample property names/prices/details.
- Replace phone, email and address.
- Replace the logo mark with your actual logo/SVG.
- Connect the contact form to your backend, Formspree, PHP, Node, etc.

The design uses Bootstrap's responsive navbar, grid, buttons and utility classes.
