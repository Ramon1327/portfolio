# PicklePro Landing Page

A portfolio-ready pickleball landing page based on the visual direction of the generated PicklePro mockup.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Bootstrap 5.3
- Bootstrap Icons
- Google Fonts

## Folder structure

picklepro/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    ├── paddle.svg
    ├── balls.svg
    ├── bag.svg
    └── cap.svg

## Run
Open `index.html` in your browser.

No PHP or build process is required.

## Included interactions
- Responsive Bootstrap navigation
- Sticky / shrinking navbar
- Active navigation highlighting
- Mobile menu closing
- Product add-to-cart demo toast
- Newsletter form demo
- Responsive testimonial controls
- Dynamic footer year
- Smooth scrolling

## Portfolio tip
Replace the demo brand, prices, testimonials, links, and SVG product artwork with your own branding/assets if you use this as a real client-facing site.
