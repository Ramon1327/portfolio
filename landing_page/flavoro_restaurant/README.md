# Flavoro Restaurant Landing Page

A responsive restaurant landing page recreated from the generated design using:

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3
- Bootstrap Icons
- Google Fonts

## Files

- `index.html` — page structure
- `style.css` — custom styling and responsive layout
- `script.js` — navbar behavior, active section highlighting, back-to-top button, dynamic year
- `assets/` — image assets cropped from the generated restaurant design

## Run

Open `index.html` in a browser.

For best results in VS Code, use the Live Server extension.

## Customize

Change the restaurant name, menu items, prices, contact details, colors, and images directly in `index.html` and `style.css`.

This is a portfolio/demo concept, so replace the placeholder business information before using it for a real client.
